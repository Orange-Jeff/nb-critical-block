NB Crash Block v5.4.5

NB Crash Block: Prevents functions.php crashes and provides full admin access when WordPress breaks

Requirement: NetBound Hub must be active.

Why this plugin

  • Seamless Integration: Designed specifically for the NetBound Ecosystem.
  • Performance Focused: Lightweight with minimal overhead.
  • Modern UI: Clean, consistent administrative interfaces.
  • AI-Era Safety: Purpose-built protections against AI-generated code errors.

Key features

  • Automated updates via NetBound Hub.
  • NB Checkup: 10-point health scanner for functions.php — detects code after closing tags, duplicate functions, unmatched braces, dangerous functions, and more.
  • Versioned Backups: Rolling 5-version backup timeline with change attribution logging.
  • AI Output Quarantine: Public API for NB plugins to validate code before writing to functions.php.
  • PHP Syntax Pre-flight: Runs php -l validation before any save, catching parse errors before they crash the site.
  • AI Code Fingerprinting: Detects placeholder function names, TODO comments, and AI-generated markers.
  • Standalone emergency recovery panel that works without WordPress.

Quick start

  1. Activate the plugin alongside NetBound Hub.
  2. Navigate to the NetB Hub dashboard to view its status.
  3. Click Run Checkup to scan your site health.
  4. Use Backup Now to create a versioned snapshot.
